Writing Modes

vertical-rl Lines start at the right edge and run downward.
vertical-lr Lines start at the left edge and run downward.
sideways-rl Every glyph is turned clockwise.
sideways-lr Every glyph is turned counter-clockwise.
mixed 日本語の縦書き with Latin words.
horizontal

A horizontal paragraph follows the vertical cards and wraps normally across the page width.
